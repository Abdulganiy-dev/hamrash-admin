Hamrash Admin · Design System

Colour palette
for a school back office

Researched against admin, education and finance products on Mobbin, then reconciled with the aubergine system already in lib/core/constants/app_colors.dart. The result: keep the brand, fill the three real gaps — an info hue, accessible muted text, and a chart ramp that survives white backgrounds.

Source Mobbin — 24 sections, 18 products Brand Aubergine #3B1F3A (locked) Canvas Linen #F6F5F2 (locked)

01 · What the research actually shows

School admin tools almost never lead with a "school" colour like blue or green. The pattern across the references is more specific: a quiet, warm canvas; one deep authoritative brand colour; and saturated colour reserved for status and data. Six recurring directions:

Warm paper neutral

Retool, Midday, Teak, Feather, Harvest. Cream or linen page, near-black type, one accent. Reads calm, expensive and printable — the strongest fit for a records-heavy admin.

Institutional navy / indigo

Stripe, Deel, Linear, Dropbox. Navy sidebar, indigo primary. Signals trust, money and permissions — what bursars and principals expect from a system of record.

Education green

Sprout Learning Portal, Skillshare, Duolingo. Deep forest surfaces with a bright mint or lime action. Friendly, but consumer-learner, not back-office.

Friendly accent blocks

Headspace, Uxcel, Canva, Upwork. Big pastel cards carrying illustration. Good for empty states and module tiles; wrong for dense tables.

Monochrome + data colour

Midday, Antimetal, Mora, Resend. Interface is greyscale; the only colour is a metric, a trend or a state. Best model for the dashboard.

Status-only saturation

Feather, Harvest, Stripe, Monarch. Tables stay neutral; green / amber / red pills carry every meaningful signal. This is the rule Hamrash already follows — keep it.

Verdict. The existing aubergine + linen + warm stone direction is the right call and matches the strongest references. Do not switch to education green or institutional navy. Instead complete the system: one absent info hue, one contrast fix, and a proper chart ramp.

05 · School-specific status sets

Same four tones, fixed meaning per module. Lock these now so a bursar, a teacher and a parent read the same colour the same way.

Attendance

Present · moss Late · amber Absent · rust Excused · teal

Attendance rate bars use the same three tones, so the chart and the register agree.

Fees

Paid · moss Part-paid · amber Overdue · rust Waived · stone

Outstanding balances are never red on a dashboard — red is a per-student state, not a total.

Results

Draft · stone Submitted · harbour Approved · teal Published · moss

A four-step lifecycle, not a warning scale. Nothing here should be amber or rust.

Enrollment & admissions

Applicant · harbour Active · moss Withdrawn · stone Graduated · aubergine

Graduated earns brand colour — it is an achievement, not an error.

07 · If the brand were ever reopened

Not a recommendation — three directions the research would support if aubergine were not already locked. Useful for the parent portal or teacher app if they should feel distinct but related.

Institutional
Navy + brass

For the owner/principal view. Prestige, board reports, printed documents.

Academic
Forest + lime

For the teacher app. Calm, growth-oriented, low glare in a classroom.

Warm
Terracotta + sand

For the parent portal. Friendly without becoming a toy.
